## Production-опыт


При работе над сервисами учитываю надёжность, обработку ошибок, восстановление после сбоев, производительность и дальнейшую поддержку системы.

Стараюсь проектировать решения так, чтобы они были управляемыми в production: с логированием, мониторингом, защитой от повторной обработки операций и возможностью безопасно реагировать на проблемы без лишнего вмешательства в работающую систему.

Есть опыт оптимизации процессов, устранения узких мест и доработки работающих систем без остановки основной функциональности.

интеграция сервисов между собой · разработка продуктов с нуля
