### Engineering

Интересны не фреймворки сами по себе, а задачи, которые возникают при эксплуатации
реальных сервисов:

- корректная обработка ошибок и повторных запросов
- идемпотентность операций
- таймауты и ограничение времени выполнения задач
- очереди и фоновые процессы
- управление ресурсами
- мониторинг и диагностика проблем
- безопасное развёртывание изменений

**Из практики.** Оптимизация алгоритма обработки сократила время выполнения задачи
с 28 минут до 2: линейный перебор заменён выборкой по активности.

Приходилось восстанавливать работу критичной части сервиса после отказа внешнего
компонента - переводить взаимодействие на другой API и отдельно прорабатывать защиту
от повторного зачисления средств.
