### Инженерная практика

**Эксплуатация.** Деплой через `git push` с post-receive хуками на несколько серверов,
supervisor и systemd. Резервное копирование PostgreSQL со сторожевым процессом, который
сообщает, если ночной дамп не появился.

**Инциденты и производительность.** При отказе сервера, обслуживавшего основную часть
платежей, перевёл проверку статусов на прямой API провайдера и написал сверку против
двойного зачисления. Обход почтовых ящиков ускорен с 28 минут до 2 - линейный перебор
заменён выборкой по активности владельца.

**Управляемость.** Идемпотентность денежных операций, флаги в конфигурации для рискованных
механик - фичу можно выключить на бою без релиза.
