## Production-опыт

Разработка не заканчивается на `git push`. Из реально решённых задач:

- восстановление работы сервиса после отказа внешнего компонента - без остановки основного процесса
- защита операций от повторной обработки и двойного зачисления
- автоматическое переключение между серверами
- контроль памяти и перезапуск зависших браузерных процессов
- резервное копирование PostgreSQL с уведомлением при сбое
- возможность отключать рискованные механики через конфигурацию, без релиза

Оптимизация алгоритма обработки сократила время выполнения задачи **с 28 минут до 2**.
